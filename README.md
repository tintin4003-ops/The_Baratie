Built an anime-themed online food ordering desktop application using Java ☕

This project focuses on creating a simple and interactive food ordering system with a clean separation between Customer and Admin roles.

🍥 Customer Features:

 • Sign up & Login
 • Change Password
 • Browse Menu
 • Place Orders
 • Leave Feedback & View Reviews
 
👨‍💼 Admin Features:

 • Secure Login & Password Management
 • Update Menu Items
 • View Orders
 • Manage Customer Reviews
